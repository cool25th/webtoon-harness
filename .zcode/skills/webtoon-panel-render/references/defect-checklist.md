# Defect Checklist — 이미지 생성 결함 전수 목록 (panel-validator 스캔 기준)

리서치 기반(일반 AI 아트 결함 분류 + 웹툰 시퀀스 실패 모드 + EP 실측)으로 정리한
결함 카탈로그다. panel-validator는 각 축(C1~C7) 검사 시 이 목록의 해당 결함을
**전수** 스캔한다. 결함별 [예방]은 prompt-smith가 프롬프트 단계에서 적용하고,
[교정]은 REGEN 지시 방식을 정한다.

각 교정 칼럼 앞의 **수리 라우팅 태그** — **[PIL]** = 국소·평면·보존 가능(편집 기반 수정:
"나머지 100% 동일 유지" 후 8~10배 확대 B1a 검사 의무) / **[RE-RENDER]** = 구도·인물·장면
오염(전체 재렌더, 참조 재강조). **BL-xx** 태그가 붙은 항목은
`references/blocklist-clauses.md`(상시 차단절 원장)와 연동된다 — 해당 컷 유형의 매니페스트에는
표준 긍정 절을 상시 주입하고(prompt-smith 의무), 신규 결함 클래스 발견 시 원장에 절을 등재하는
것이 표준 절차다(validator 의무 — 등재 후 다음 매니페스트부터 전 컷 자동 주입 + 진행 중
매니페스트 소급 주입).

## 스캔 원칙

1. **전수**: 표본추출·집계 도장 금지 — 패널마다 A~F 전 카테고리 훑기.
2. **우선순위**: 독자가 바로 알아챌 것(해부학·텍스트·화자) > 연속성 > 기타.
3. **교정 방식 선택(수리 라우팅)**: 국소·평면·보존 가능(손·텍스트·소품·맨벽/계산대면 등) = **[PIL] 편집 기반 수정**, 구도·인물·장면 오염(인원·장소·프레임 구조 등) = **[RE-RENDER] 전체 재렌더(참조 재강조)**, 반복 실패 3회 = 샷 재구성(구도 변경) 제안.
4. **기록**: validation.md에 결함 코드(A1~F3·BL-xx)로 남겨 재발 패턴을 추적한다.
5. **차단절 파이프라인**: 신규 결함 클래스 확정 시 validator는 `references/blocklist-clauses.md`에 표준 긍정 절(영문 단일 문장)을 즉시 등재한다(클래스 최초 발견 → 원장 등재 → 이후 전 매니페스트 적용이 표준 절차). prompt-smith는 매니페스트 작성 시 해당 컷 유형에 적용되는 모든 절을 상시 주입하고, 같은 세션 진행 중 매니페스트에는 소급 주입한다(APPROVED-MD5 핀 컷 제외). 결함을 매번 검증에서 잡는 것이 아니라 프롬프트에서 선제 차단한다 — ep01 펜꽂이 3연속(§C-7)이 이 루프 누락의 실측 사례다.
